# 档案元数据核对台

`sologsb-1020` 是一个用于口述史与手稿档案元数据比对的本地优先前端工作台，使用 Qwik、TypeScript 和 Qwik UI 构建。

## 功能

- 导入 A / B 两组记录，支持 JSON 数组、制表符和竖线分隔文本。
- 按标题、日期、人物、地点和编号加权匹配，显示综合分数与判断依据。
- 键盘密集复核：J/K 移动、Enter 合并、C/R 确认或忽略，支持批量操作。
- 合并时逐字段并排展示 A / B 来源，每个冲突字段可单独保留或拼接。
- 保存原始记录、字段来源选择、合并结果和忽略动作，形成完整审计轨迹。
- 支持撤销重做、离线 localStorage 保存和 JSON 核对包导出。
- 县馆离线核对：检出工作包后可断网作业、重开浏览器自动续做，封包带回中心。
- 回传包按**包身份（packageId）**去重，重复包不重复入账；按**检出快照**逐字段三方定位改动。
- 无冲突内容直接汇入；快照变化或两人结论不同的改动进入**待裁决队列**，列出涉事包、影响记录与字段（基线 / 中心现值 / 县馆来值），人工采纳或忽略前不进入最终核对包。
- 合并、忽略与裁决动作全部写入审计轨迹，已接收包在台账中可查。
- 大量记录采用分批窗口渲染，匹配计算限制每条记录的候选数，避免一次挂载全部行。

## 技术栈

- Qwik 1.20
- TypeScript 5.9
- Qwik UI Headless `@qwik-ui/headless`
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务使用 Vite 默认端口，不在源码中硬编码宿主端口。

## 生产构建

```bash
npm run build
npm run preview
```

静态产物输出到 `dist/`。

## Docker

```bash
docker build -t sologsb-1020 .
docker run --rm -p 10020:80 sologsb-1020
```

nginx 在容器内监听 `80`，宿主端口 `10020` 由根端口表或运行命令映射。

## 数据说明

记录和审计轨迹保存在当前浏览器。导入新记录后自动重新计算候选匹配，但不会自动确认或覆盖任何字段。

## 离线包检出与合并

1. **检出（中心 → 县馆）**：中心点「检出离线工作包」，按当前快照（revision 与每条记录的字段哈希）生成 `offline-work-package` 并下载，本机切换为该县馆的离线工作台。
2. **离线核对（县馆）**：断网完成新增、字段编辑、匹配确认 / 忽略与逐字段合并；每项改动都记录检出基线值。会话保存在 localStorage（键 `sologsb-1020-work-package-v1`），重开浏览器自动恢复，也可用工作包文件重新打开继续处理。
3. **封包回传（县馆 → 中心）**：点「封包回传」生成 `offline-check-package`，带包身份、检出 revision、记录快照哈希、变更与县馆审计轨迹。
4. **合并入中心**：中心点「接回离线包」：
   - 相同 `packageId` 的包识别为重复包，不重复入账，仅记一条审计；
   - 新增记录、快照未变的编辑、中心尚无结论（或结论相同）的复核、快照一致的合并直接汇入；
   - 中心也改过同一字段、合并所依据的记录已漂移、或两人对同一匹配给出不同结论时，改动进入**待裁决队列**，展示涉事包、影响记录与字段的基线 / 中心 / 县馆三方取值；
   - 裁决「采纳」才把县馆改动并入最终核对包，「忽略」保留中心现状；两种动作与接包、去重、县馆审计均永久留痕。

## 引擎自检

```bash
npm run verify
```

在 Node 下跑 7 组场景（直接汇入、重复包去重、字段快照冲突、结论冲突、离线合并、离线重开续做、新增记录增量匹配）。
