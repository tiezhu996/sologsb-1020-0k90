# 档案元数据核对台

`sologsb-1020` 是一个用于口述史与手稿档案元数据比对的本地优先前端工作台，使用 Qwik、TypeScript 和 Qwik UI 构建。

## 功能

- 导入 A / B 两组记录，支持 JSON 数组、制表符和竖线分隔文本。
- 按标题、日期、人物、地点和编号加权匹配，显示综合分数与判断依据。
- 键盘密集复核：J/K 移动、Enter 合并、C/R 确认或忽略，支持批量操作。
- 合并时逐字段并排展示 A / B 来源，每个冲突字段可单独保留或拼接。
- 保存原始记录、字段来源选择、合并结果和忽略动作，形成完整审计轨迹。
- 支持撤销重做、离线 localStorage 保存和 JSON 核对包导出。
- 大量记录采用分批窗口渲染，匹配计算限制每条记录的候选数，避免一次挂载全部行。

## 离线包合并（中心 ↔ 县馆）

县馆核对员常离线工作，核对包带回中心后**三向合并**，不再整体替换中心工作区：

1. **基准快照包（中心 → 县馆）**：中心导出当前记录、匹配、既有合并与快照哈希（SHA-256 摘要）。县馆在「离线包同步 → 接收核对包」载入（载入会替换本机工作区，需二次确认），本机切换为县馆离线模式。
2. **离线核对包（县馆 → 中心）**：县馆离线期间的确认、忽略、合并和记录改动，都按基准快照逐条定位，仅包含相对快照的差异。
3. **中心收包**：
   - 按**包身份**（包 ID）去重，重复包不重复入账（仍登记一条"重复"回执并写审计）。
   - 无冲突内容（中心未动、或双方结论一致）**直接汇入**。
   - **快照变化**（中心改过同一字段、删除了记录、匹配已不存在）或**两人结论不同**时，改动进入**待裁决队列**，列出涉事包、来源站点和每个影响字段的基准/中心/县馆三方值。
   - 待裁决项确认前，相关记录标记为「待裁决」且**不进入最终核对结果导出**；可全部采用县馆、全部保留中心，或对记录逐字段选择，也可忽略。
   - 并入、忽略、裁决动作全部写入审计轨迹；包台账记录每个包的身份、快照哈希、改动计数与裁决数。
4. 包台账、待裁决队列、审计和站点状态都保存在 localStorage，离线重开浏览器后继续处理。

入口：顶栏「离线包同步」（快捷键 Ctrl/⌘ + Shift + O）。

### 同步引擎测试

```bash
npm run test:sync
```

覆盖重复包幂等、干净汇入、结论分歧、快照变化、逐字段裁决、忽略、合并动作汇入和新增记录补算匹配等场景。

## 技术栈

- Qwik 1.20
- TypeScript 5.9
- Qwik UI Headless `@qwik-ui/headless`
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务使用 Vite 默认端口，不在源码中硬编码宿主端口。

## 生产构建

```bash
npm run build
npm run preview
```

静态产物输出到 `dist/`。

## Docker

```bash
docker build -t sologsb-1020 .
docker run --rm -p 10020:80 sologsb-1020
```

nginx 在容器内监听 `80`，宿主端口 `10020` 由根端口表或运行命令映射。

## 数据说明

记录和审计轨迹保存在当前浏览器。导入新记录后自动重新计算候选匹配，但不会自动确认或覆盖任何字段。
